# DNA Sequence Analyzer

A Python-based project for performing basic analysis of DNA sequences.

## Introduction
The DNA Sequence Analyzer accepts a DNA sequence containing A, T, G and C and performs basic sequence analysis.

## Objectives

- Validate a DNA sequence
- Count DNA bases
- Find unique DNA bases
- Find the length of the sequence
- Find the K-th DNA base
- Divide the DNA sequence into two parts
- Calculate GC content
- Generate the complementary DNA sequence
- Generate the reverse DNA sequence

## Python Concepts Used

- Lists
- Dictionaries
- Sets
- Arrays / sequence indexing
- Array partitioning
- K-th element
- Conditional statements
  

## Features

### DNA Validation
Checks whether the sequence contains only A, T, G and C.

### Base Counting
Counts the number of A, T, G and C bases.

### List
Stores individual DNA bases in a list.

### Dictionary
Stores the count of each DNA base.

### Set
Identifies unique DNA bases.

### K-th Element
Finds the DNA base at a selected position.

### Array Partitioning
Divides the DNA sequence into two parts.

### GC Content
Calculates the percentage of G and C bases.

### Complementary DNA
Generates the complementary DNA sequence.

### Reverse DNA
Generates the reverse DNA sequence.

## Requirements
- Python 3.x
- IDLE or any Python IDE

No external libraries are required.

## How to Run
1. Download DNA_py.
2. Open it using Python IDLE.
3. Run the program.
4. Enter a DNA sequence using A, T, G and C.
5. Enter the required K position.
6. View the analysis results.
